# 规则口径

卡牌文字没写清楚、或者能有几种合理理解的情形，在这里定下来。`test/cards/` 里名字以 `[口径]` 开头的用例，就是按这里的结论写的断言。

改口径的顺序：先改这份文档，再改对应的 `[口径]` 用例，最后改引擎。依据优先级：卡牌正文和注释 > 规则书补充（`reference/` 里的调研资料）> 和同类情形保持一致。

## 二、待定：影响面大的原则

### A. 瞬移算不算「停到」那一格

- **现状**：单人瞬移会结算落点，包括催眠蛇、跟屁虫、灵魂伴侣、电灯泡、漩涡传送、大明星换位、魔法健将掷 3。同时瞬移不结算，包括大海怪、镜像世界、传送带、魔法健将掷 2。
- **受影响的情况**：
  - 大海怪卷过来的人不付小旅馆房费、不抢野猪、不被漩涡传走。
  - 镜像世界翻到 28/29 格，不会被撞头虫撞回去。
  - 魔法健将掷 2 把人传到星星格，不给分。
  - 瞬移越过第 14 格的变数招牌，不翻变数卡。
- **规则书倾向**：瞬移也算停到。芭芭雅嘎的补充写着「催眠师把我拉过去，催眠师也会被绊倒」。
- **选项**：① 维持现状；② 同时瞬移也结算落点（按行动顺序逐个结算）。

### B. 停格触发之后，人被别的效果带走了

赛道格和当前玩家的技能先结算。结算完人已经不在原格时：

- **现状**：
  - 芭芭雅嘎照样绊倒（已定 5）。
  - 大嘴怪不吃人：停在箭头格，被箭头带走后不吃原格的人。
  - 浪漫鳄按结算时的人数重新判断：大嘴怪先吃掉一人后，浪漫鳄不前进。
  - 停在皮纳塔分格，被撞头虫撞回去，就拿不到那格的分。
- **选项**：
  - ① 作用在停下的那个人身上的效果（绊倒、付房费、抢野猪、拿分）照样生效；依赖格子里人数的效果（大嘴怪、浪漫鳄）按结算时判断。
  - ② 全部按停下那一刻生效。
  - ③ 维持现状。

### C. 主移动之前摔倒，这一回合还能不能主移动

- **现状不一致**：
  - 二代「回合开始」阶段摔倒，这回合不能动。例如被大明星换到石头上。
  - 一代「主移动前」技能阶段摔倒，这回合照常动、下回合才跳过。例如催眠蛇把芭芭雅嘎拉到身边、啦啦队长自己踩到石头、电灯泡跳到芭芭雅嘎的格子。
- **相关问题**：被绊倒跳过主移动的那一回合，「主移动前」的技能（啦啦队长、催眠蛇、派对熊、可爱废柴）现在都不能用。
- **规则书写法**：「跳过下一次主要移动」。
- **选项**：① 统一成「这回合就不能动」；② 统一成「下回合才跳过」；③ 维持现状。

### D. 冲线的人还算不算在场

- **现状**：不算。模仿猫、野兔、飙车魔、搅局鬼判断「领跑」「其他所有人」时，只看还在赛道上的人。
- **另一种理解**：冲线的人仍然排在前面。这样会影响：
  - 飙车魔不再领先所有人。
  - 搅局鬼要触发取消。
  - 模仿猫可以抄冲线者的技能。
